# Білім PRO

Сайт: https://bilim-pro.vercel.app

Оқу платформасы для 5–11 классов на казахском языке: информатика, математика, физика и математическая грамотность (все четыре — предметы ҰБТ). Учителя могут регистрироваться, открывать классы, видеть прогресс учеников и публиковать собственные уроки.

Жоба жетекшісі: Инкарбекова Маржан Асилхановна, информатика пәнінің мұғалімі.
Мектеп: Бурыл ауылы, №6 орта мектеп.
Оқушы авторлар: Амангелді Іңкәр, Кубеева Нұрай.

## Что нового в версии 4

- **Регистрация учителей.** Раздел «Кабинет»: регистрация и вход по email и паролю, профиль, смена пароля, удаление аккаунта.
- **Классы.** Учитель создаёт класс и получает 6-значный код (и ссылку вида `…/#join/КОД`). Ученик вводит код, имя и 4-значный PIN — и его прогресс (XP, прочитанные уроки, тесты, ҰБТ-тренинги) автоматически отправляется учителю. Таблица класса, карточка каждого ученика, экспорт в CSV.
- **Конструктор уроков.** Учитель пишет теорию, ключевые правила, пример и 3–10 тестовых вопросов. Урок появляется в каталоге для всех или только для своих классов.
- **Страница «Мұғалімдер»** — публичный список учителей (по желанию учителя).
- **Новые предметы:** Математика (14 уроков), Физика (11), Математикалық сауаттылық (7). У каждого урока — теория, разобранный пример, 3 вопроса и пошаговая «доска решений».
- **ҰБТ-тренинг по любому из 4 предметов**, олимпиадные задачи с фильтром по предмету (22 задачи).
- **Две новые лаборатории:** «График функции» (y = kx + b) и «Закон Ома» (интерактивная цепь).
- **Премиум-дизайн:** шрифт Inter (локально, с поддержкой всех казахских букв), новые кнопки, карточки предметов, формы, крупнее и читаемее текст. Цветовая гамма сохранена.

Итого: 60 уроков, 180 вопросов, 22 олимпиадные задачи, 6 лабораторий.

## Два режима работы

Сайт сам определяет, есть ли сервер:

| Режим | Как опубликовать | Что работает |
|---|---|---|
| **Облачный** (рекомендуется) | Netlify (через Git или CLI) **или Vercel** с подключённым Upstash Redis | Всё. Аккаунты учителей, классы и уроки хранятся на сервере и доступны с любого устройства. Ученики подключаются со своих телефонов. |
| **Локальный** | Netlify Drop (перетащить папку) или открыть `index.html` | Все уроки, тесты, лаборатории. Кабинет учителя тоже работает, но данные хранятся только в этом браузере, поэтому ученики с других устройств не смогут войти в класс. На странице кабинета это явно написано. |

### Публикация с регистрацией (облачный режим)

Netlify Drop не запускает серверные функции, поэтому для регистрации учителей нужен один из двух способов:

**Через GitHub (проще всего):**
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. В Netlify: *Add new site → Import an existing project* → выберите репозиторий.
3. Настройки уже в `netlify.toml` — ничего менять не нужно. Нажмите *Deploy*.

**Через Netlify CLI:**
```
npm install
npx netlify-cli deploy --prod
```

Netlify Blobs включается автоматически, отдельная база данных не нужна. Рекомендуется (необязательно) добавить в *Site configuration → Environment variables* переменную `BILIM_SECRET` — длинную случайную строку для подписи сессий. Без неё секрет генерируется автоматически и хранится в Blobs.

Проверка: откройте `https://ваш-сайт.netlify.app/api/bilim?p=/health` — должно появиться `{"ok":true,"mode":"cloud"}`.

### Публикация на Vercel

На Vercel нет Netlify Blobs, поэтому данные хранятся в бесплатной базе Upstash Redis (подключается в пару кликов, код менять не нужно).

1. Загрузите папку в репозиторий GitHub и импортируйте его в Vercel: *Add New → Project*. Framework Preset: **Other**, Build Command — пусто, Output Directory — пусто (корень). Нажмите *Deploy*.
   Без GitHub: `npx vercel --prod` в папке проекта.
2. В проекте Vercel: *Storage → Create Database* (или *Marketplace*) → **Upstash → Redis** → создайте базу и нажмите *Connect* к проекту. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` (подходят и `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`).
3. Рекомендуется добавить переменную `BILIM_SECRET` — длинную случайную строку.
4. Сделайте *Redeploy*, чтобы функция увидела переменные.

Проверка: `https://ваш-сайт.vercel.app/api/bilim?p=/health` должен вернуть `{"ok":true,"mode":"cloud"}`. Если база не подключена, ответ будет `"mode":"no-storage"` — сайт продолжит работать в локальном режиме.

Файлы для Vercel: `api/bilim.mjs` (функция), `vercel.json` (заголовки безопасности, аналог `_headers`), `.vercelignore`. Файлы Netlify Vercel игнорирует и наоборот, так что один и тот же архив подходит для обеих платформ.

### Локальная проверка с сервером

```
node dev-server.mjs      # http://localhost:8888, данные в .data/db.json
node tests/api.test.mjs  # 45 тестов API
```
Нужен только Node.js 18+, без установки пакетов.

### Безопасность

Пароли хэшируются PBKDF2-SHA256 (120 000 итераций) с солью, PIN учеников — так же. Сессии — подписанные HMAC-токены на 30 дней. Блокировка на 10 минут после 6 неверных попыток входа; ограничение частоты регистраций; запросы с чужих сайтов отклоняются. Email учителя никому не показывается. Весь пользовательский текст экранируется при выводе.

## Быстрый запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в современном браузере: Chrome, Edge, Firefox или Safari.
3. Все файлы должны оставаться рядом. Интернет для уроков и упражнений не требуется.

Предпочтительно пользоваться сайтом по адресу Netlify: локальные файлы в разных браузерах могут иметь особенности сохранения прогресса.

Для обновления замените файлы и загрузите всю папку заново в ручной раздел Deploys своего проекта. Используйте существующий проект, чтобы сохранить адрес.

## Что работает (информатика, исходная версия)

- Навигация по разделам, адаптивная мобильная версия, поиск по темам и фильтры классов.
- 28 мини-уроков: по 4 на каждый класс с 5-го по 11-й. Краткая теория, пример и ключевые выводы.
- 84 уникальных вопроса: по 3 на урок, один правильный ответ, перемешивание вариантов, объяснение.
- 14 олимпиадных задач: по 2 на каждый класс. Проверка числового результата, подсказки, решение и примеры Python.
- Тренировочный тест: 30 случайных вопросов из банка 8–11 классов (48 вопросов), 45 минут, переход между вопросами, автоматическое завершение и разбор всех ответов. Это авторская тренировка, а не официальная база ҰБТ и не копия его структуры.
- Четыре лаборатории: двоичный код, пошаговая сортировка, пиксельная графика 8×8 и робот с препятствиями.
- Прогресс, XP, уровни, значки, история результатов; экспорт/импорт JSON.
- Печать урока без элементов навигации.
- Страница проекта и авторов.

## Прогресс и баллы

Прочитанный урок — 20 XP. Каждый новый правильный ответ в лучшем результате мини-теста — 5 XP. Решённая олимпиадная задача — 40 XP. Исследованная лаборатория — 25 XP. Повторное выполнение не даёт повторных баллов.

Для лабораторий: соберите двоичное число из миссии; доведите сортировку до конца; нарисуйте пиксельную картинку и скачайте SVG; проведите робота к флагу. Каждая лаборатория даёт достижение один раз.

Олимпиадные задачи проверяют число для конкретного условия, а не произвольную программу. Просмотр решения до ответа не даёт достижение в этой попытке. Код из уроков и решений не исполняется браузером — его можно проверить в Python.

Прогресс хранится в localStorage этого браузера. Открытый тест хранится в sessionStorage текущей вкладки; при перезагрузке можно продолжить с тем же временем окончания. Если ушли в другой раздел, время продолжает идти; при возврате истёкший тест завершится. Закрытие вкладки может удалить незавершённую попытку. Разбор последнего теста хранится в памяти текущей вкладки, а итоговая оценка — в истории прогресса.

Личный прогресс ученика хранится в браузере. Если ученик подключился к классу, сводка прогресса дополнительно отправляется учителю. Для переноса личного прогресса между устройствами используйте экспорт и импорт. Перед импортом сайт показывает подтверждение замены данных.

## Редактирование

- `subjects.js` — список предметов, уроки математики, физики и мат. грамотности, олимпиадные задачи по ним. Функция `subjectLesson(...)` дополнительно принимает 4 шага пошагового объяснения.
- `bilim-core.js` — серверная логика (учителя, классы, ученики, уроки). Один и тот же файл работает в Netlify Function и в браузере в локальном режиме.
- `api.js` — определение режима и запросы к API; `teacher.js` — кабинет учителя, страница учителей и вход ученика в класс.
- `server/http.mjs` — общий HTTP-слой API; `netlify/functions/api.mjs` — функция Netlify (Blobs); `api/bilim.mjs` — функция Vercel (Upstash Redis); `dev-server.mjs` — локальный сервер; `tests/` — тесты API.
- `pro.css` — премиум-слой дизайна (шрифт, кнопки, формы, кабинет).
- `data.js` — 28 уроков и 14 задач по информатике. Вызов `lesson(...)` задаёт класс, уникальный ID, заголовок, раздел, время чтения, абзацы, выводы, пример и три вопроса. У каждого вопроса указываются текст, правильный ответ, три неверных варианта и объяснение.
- `app.js` — страницы, интерактивы, подсчёт результатов, авторы на странице «Жоба туралы».
- `style.css` и `premium.css` — палитра, карточки, размеры, адаптация и анимации. Учитывается системная настройка уменьшения движения.
- `index.html` — название, метаданные, меню, подвал.
- `assets/favicon.svg` — знак сайта, нарисованный в SVG.
- `_headers` — заголовки защиты для Netlify.

CDN, внешних веб-шрифтов, платных API и ключей нет. Три библиотеки из GitHub включены локально в папку `vendor/`, вместе с лицензиями и сведениями о версиях. ЖИ-чат не подключён. Чтобы позже подключить реальный ЖИ API, понадобится серверная функция и изменение политики connect-src; секретные ключи нельзя вставлять в браузерный JavaScript.

## Premium Studio: дизайн и анимации

- Тёмная изумрудная навигация, мягкие градиенты, объёмные кнопки, иллюстрации курсов на SVG.
- 3D-чип на главной: плавающие карточки, световые импульсы по дорожкам и мягкое движение.
- Последовательное появление карточек при прокрутке, анимация чисел и полос прогресса.
- Лёгкий наклон карточек мышью. На сенсорных экранах наклон отключён, гироскоп не используется.
- Все 28 уроков имеют авторскую визуальную объясняющую сцену из 4 шагов. Можно запускать автоматически, ставить на паузу и переходить по шагам.
- Сортировка плавно меняет высоты столбцов, робот перемещается между клетками, пиксели и биты реагируют на нажатия.
- Конфетти за новые достижения и успешные тесты.
- Переключатель «Анимация» в верхней панели. Выбор сохраняется отдельно от учебного прогресса. Системная настройка уменьшения движения имеет приоритет; она отключает декоративные анимации, но не мешает пошаговому объяснению.
- При переходах освобождаются таймеры объяснений, наблюдатели прокрутки и эффекты карточек. Во время скрытой вкладки объяснение ставится на паузу.

## Canva Visual Learning edition

Для каждого основного раздела в Canva создана отдельная иллюстрация: главная, информатика, олимпиада, ҰБТ, лаборатории, достижения и проект. Изображения согласованы по палитре и стилю, а сайт сохраняет самостоятельную визуальную идентичность.

Файлы находятся в `assets/canva/`, источники и ссылки на оригиналы — в `assets/canva/SOURCES.json` и `Canva_Gallery.html`. Коннектор предоставил локальные превью размером 199×112 пикселей, поэтому на сайте они используются как небольшие иллюстрации без увеличения сверх исходного размера. Полноразмерные изображения доступны в Canva по сохранённым ссылкам; они не требуются для запуска сайта. Для замены на оригиналы скачайте их в своём Canva и замените соответствующие JPG в `assets/canva/` с теми же именами. Загрузка внешних изображений при работе сайта не нужна.

В уроках добавлены 28 предметных моделей, меняющихся по четырём шагам: переменные и выполняемая строка кода, выбор разрядов двоичного числа, перенос элементов массива, выделение среза строки, логические сигналы, фильтрация и сортировка таблицы SQL, обход графа BFS, адрес и маска сети, связи таблиц, функции, объекты и другие процессы. Шаги управляются кнопками и автопроигрыванием; объяснения работают и с выключенной анимацией. Автошаг длится 2,6 секунды; любой шаг можно остановить для чтения.

`scenes.js` формирует наглядные модели, `art.js` размещает иллюстрации по разделам, `canva.css` оформляет изображения и учебные сцены. Размеры подписей в интерфейсе увеличены, чтобы анимации сопровождались читаемым текстом.
